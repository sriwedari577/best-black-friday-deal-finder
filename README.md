Friday Finder — a working Black Friday and Cyber Monday deal finder with 56 real deals checked on 27 November 2026 at their stores or in deals sources naming the store. Each deal shows its product, store, store link, sale price, usual price, discount, when its price was checked, and a verdict on whether it is really a deal (new low, strong price, or routine sale) with the evidence. Search and filters by category, store, discount, and verdict work; a Compare view shows the same product's price at more than one store; desktop and phone layouts; static files with no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the hand-in output instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
